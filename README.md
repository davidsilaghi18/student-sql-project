#  Student Management System – SQL Project

This is a simple SQL project using PostgreSQL to manage students and their grades.  
It includes a basic schema, sample data, and example queries.

##  Files
- `schema.sql` – defines the database tables
- `seed.sql` – inserts sample data
- `queries.sql` – contains SQL queries to retrieve and analyze data

##  How to Use

1. Open a PostgreSQL terminal:
   ```bash
   psql -U postgres
2. Create and connect to a new database (optional):
   ```sql
   CREATE DATABASE studentdb;
   \c studentdb
